# Parked code (not part of the build)

`second-engine-prototype/` is an alternative raster-cel engine written in parallel by mistake: perspective guide
types (1-5 point, isometric, curvilinear), a procedural template catalog (heads, mannequin poses, motion cycles,
animals, objects), camera keys, and GIF/ZIP/WebM export helpers. It was never run end to end and is excluded from
tsconfig (`include: ["src"]`). It is kept only as raw material for Phase 3-6 work; port ideas, not files.
